# Class maps

The lookup tables in `@ui-kit/utils/colors` that turn a value (item quality, class, spell school, resource, faction, tone) into its colour classes. A table keyed by a proto enum shows the enum name. Reach for one of these rather than building a class name from a value: a class assembled at runtime is never generated.
